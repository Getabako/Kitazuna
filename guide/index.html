UnityとAIをつなぐ手順

最終更新：2026年11月6日

このページは、『Kitazuna 未来杉の守護者 公式ファンブック 1 男鹿編』の手引きで使う準備の手順です。本では「何のために、何をつなぐのか」を書き、ボタンの位置や入力する命令は、このページにまとめました。

UnityもAIも、手順や画面がよく変わります。変わったら、本ではなくこのページを直していきます。

  3. AIを用意する

0用意するもの

パソコンMac または Windows。スマホやタブレットだけではできません。
Unityのアカウント無料で作れます。個人や小さな規模なら、無料のプランで始められます。
AIパソコンの中のファイルを読んだり、命令を打ったりできるAI。たとえば Codex や Claude Code。チャット画面だけのAIでは、Unityを動かせません。
ターミナル文字で命令を打つ画面です。Macは「ターミナル」、Windowsは「PowerShell」。最初から入っています。

ターミナルに慣れていなくても大丈夫です。このページの命令は、そのままコピーして貼れば動きます。分からない表示が出たら、その文字をそのままAIに貼って「これはどういう意味？次に何をすればいい？」と聞いてください。

1Unityをダウンロードして、プロジェクトを作る

  1. Unityの公式ページから Unity Hub をダウンロードして入れます。
    https://unity.com/ja/download
  2. Unity Hub を開いてサインインし、「インストール」から Unity 6 の LTS（長く使える安定版）を入れます。ブラウザで遊べる形にしたいなら、追加のモジュールで Web Build Support にも印を付けます。
  3. 「新しいプロジェクト」から 2D のテンプレートを選び、名前と保存場所を決めて作ります。保存場所は、あとで使うので覚えておきます。

『Kitazuna』は Unity 6.5 で作っています。これから始めるなら、その時点の Unity 6 の LTS で問題ありません。

2AIを用意する

パソコンの中で作業できるAIを1つ用意します。入れ方は各公式ページに沿ってください。

  • Codex（OpenAI）：https://openai.com/codex/
  • Claude Code（Anthropic）：https://www.anthropic.com/claude-code

入れたら、ステップ1で作った Unity プロジェクトのフォルダを、AIの作業場所として開きます。

3Unity CLIを入れる

Unity CLI は、Unity を文字の命令で動かすための公式の道具です。AIはこれを使って、Unityの中を調べたり、動かしたり、確かめたりします。2026年11月の時点ではベータ版です。

Mac
curl -fsSL https://public-cdn.cloud.unity3d.com/hub/prod/cli/install.sh | UNITY_CLI_CHANNEL=beta bash
Windows（PowerShell）
$env:UNITY_CLI_CHANNEL='beta'; irm https://public-cdn.cloud.unity3d.com/hub/prod/cli/install.ps1 | iex

入れ終わったら、ターミナルを一度閉じて開き直し、次の2つを打ちます。1つ目でバージョンが出れば入っています。2つ目でブラウザが開くので、Unityのアカウントでサインインします。

Mac / Windows 共通
unity --version
unity auth login

4プロジェクトにPipelineを入れる

Pipeline は、Unity CLI からの命令を Unity エディタの中で受け取るための部品です。プロジェクトごとに入れます。

  1. Unity エディタで、ステップ1のプロジェクトを開いておきます。
  2. ターミナルで、プロジェクトのフォルダに移動します（cd のあとに、フォルダをターミナルへドラッグすると場所が入ります）。
  3. 次の命令を打ちます。
Mac / Windows 共通
unity pipeline install

しばらくすると、Unity エディタの上のメニューに Pipeline が増えます。これが見えたら入っています。

5つながったか確かめる

Unity エディタを開いたまま、ターミナルで次を打ちます。

Mac / Windows 共通
unity pipeline list
unity command

1つ目で、Pipeline を入れたプロジェクトが一覧に出ます。2つ目で、Unity に頼める命令の一覧（再生する、テストする、画面を撮る など）がずらっと出れば、つながっています。

最後に、Unity に小さな計算を頼んでみます。2 と返ってくれば成功です。

Mac / Windows 共通
unity command eval "return 1+1;"

6AIに「Unityを使っていい」と伝える

AIは、何も言わなければ Unity CLI があることを知りません。プロジェクトのフォルダに、AIへの約束ごとを書いたファイルを置きます。Codex なら AGENTS.md、Claude Code なら CLAUDE.md という名前です。中身は、たとえば次のように書きます。

このフォルダは Unity のプロジェクトです。
Unity の中を調べたり、動かしたり、確かめたりするときは Unity CLI を使ってください。
- 使える命令は「unity command」で一覧を見てから選ぶ
- 変更したら、必ず「unity command recompile」で通るか確かめる
- 大きく作り替える前に、何をするかを先に私に説明する

準備ができたら、最初の頼みごとをしてみましょう。本の手引きで使う頼み文です。

Unity CLI を使って、主人公が1画面を左右に歩くだけの2Dゲームを作りたいです。
いきなり全部作らず、作る順番を小さく分けて、1つずつ一緒に進めてください。
1つ終わるごとに、Unity で何が変わったかと、私が確かめることを教えてください。

7つまずいたとき

  • まず診断。ターミナルで unity doctor を打つと、何が足りないかを調べてくれます。
  • 出た文字をそのままAIに貼る。エラーの文や、画面のスクリーンショットをそのまま渡して「どうすればいい？」と聞くのがいちばん早い解決法です。
  • 「unity」が見つからないと言われる。ターミナルを閉じて開き直してください。それでもだめなら、そのメッセージをAIに貼ります。
  • 命令が届かない。Unity エディタでプロジェクトを開いているか、メニューに Pipeline があるかを確かめます。

気をつけること

Unity CLI と Pipeline は、まだベータ版・実験版です。使い方が変わることがあります。

AIに Unity CLI を渡すのは、自分のパソコンを触らせるのと同じです。大事なプロジェクトは、始める前にフォルダごと複製してから試してください。eval は Unity の中で何でも実行できる命令なので、自分のパソコンの中だけで使います。
